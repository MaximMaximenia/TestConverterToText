# Лендинг вебинара — Мейнард Скринда

Статический сайт (HTML/CSS/JS, без сборки). Открывается прямо `index.html` в браузере или через любой статический хостинг (GitHub Pages, Netlify, Vercel и т.п.).

## Что редактировать

Все настраиваемые вещи — в одном файле: **`js/config.js`**.

- **Дата и время вебинара** → `webinarDate`. Таймер сверху сайта и в блоке записи сам всё пересчитает.
- **Цены** → `priceOld`, `priceNew`, `freeUntilText`.
- **Видео на главном экране** → `videoSrc` (файл видео) и `videoPoster` (картинка-заставка до нажатия play).
- **Имя эксперта** → `expertName`.
- **Куда отправлять заявки с формы** → `formEndpoint` (URL вашей CRM/бота). Пока пусто — форма просто показывает подтверждение на странице.

Файл прокомментирован по-русски, менять можно без знания кода.

## Как добавить своё видео

1. Положите файл видео (например, `webinar-preview.mp4`) в папку `assets/`.
2. В `js/config.js` укажите `videoSrc: "assets/webinar-preview.mp4"`.
3. Сейчас в `assets/` лежит только SVG-заставка `video-poster.svg` (сгенерированная обложка для плеера) — само видео нужно добавить отдельно, файл в чат не прикрепился.

## Как добавить свои фото

- Фото эксперта: замените блок-заглушку `.about__photo-placeholder` в `index.html` (секция «Обо мне») на `<img src="assets/ваше-фото.jpg" alt="...">`.
- Аватарки в отзывах сейчас — инициалы на золотом фоне; при желании замените `<span class="review-card__avatar">` на `<img>`.

## Структура

```
webinar-landing/
  index.html        — разметка страницы
  css/style.css      — стили (палитра: чёрный / белый / золото)
  js/config.js        — настройки (таймер, цены, видео) — редактировать тут
  js/script.js        — логика (таймер, видео, форма)
  assets/             — изображения и видео
```
